 📂 Phase 05: Catalog Domain (Sub-Cent Price Precision & Conversions)

### Developer Instruction Prompt
Generate the Filament v5 **`ProductResource`** and locate it inside `app/Filament/Resources/Products/`. Decouple all form and table schemas following the clean v5 design specifications:

1. **`Schemas/ProductForm.php`**:
   * Implements the Filament v5 Schema API (`configure(Schema $schema): Schema` returning `$schema->components([...])`).
   * Configures fields inside a flat `Section::make()`.
2. **`RelationManagers/VariantsRelationManager.php`**:
   * Manages SKU variant mappings and GTIN barcodes.
   * **Sub-Cent Pricing**: Set step configurations (`->step('0.0001')`) and default placeholders (`'0.0000'`) on price fields to support decimal 12,4 data inputs.
3. **`RelationManagers/ConversionsRelationManager.php`**:
   * Outlines conversion factors (e.g. `1 Box = 24 Pieces`).
4. **`RelationManagers/PricesRelationManager.php`**:
   * Enables administrators to define location-scoped pricing overrides with 4-decimal precision.

```php
// app/Filament/Resources/Products/Schemas/ProductForm.php
namespace App\Filament\Resources\Products\Schemas;

use Filament\Schemas\Schema;
use Filament\Schemas\Components\Section;
use Filament\Forms\Components\TextInput;

class ProductForm
{
    public static function configure(Schema $schema): Schema
    {
        return $schema->components([
            Section::make()->schema([
                TextInput::make('sku')->label('BASE PRODUCT SKU')->required(),
                TextInput::make('name')->label('PRODUCT FAMILY NAME')->required(),
                TextInput::make('category')->label('CATEGORY'),
                TextInput::make('reorder_point')->label('REORDER POINT')->numeric()->default(0),
            ])->columns(2),
        ]);
    }
}
```
