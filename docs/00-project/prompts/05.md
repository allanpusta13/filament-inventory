# Prompt 5 — Product Resource

Generate a Filament v5 resource for the Product model (Laravel 13, Filament 5
file structure: separate Schemas/ and Tables/ files). Fields: sku, name,
category, unit, reorder_point. Table should show a computed "total stock"
column using Product::totalQuantity() (sum across all warehouses) and
highlight rows where total stock <= reorder_point. Everyone can view;
only admins can create/edit/delete (use canCreate/canEdit/canDelete
returning auth()->user()->isAdmin()).
