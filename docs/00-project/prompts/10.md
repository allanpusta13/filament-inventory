### Phase 10: Audit Ledgers & In-Transit Tracking Resources

#### Objective
Construct read-only FilamentPHP v5 resources to support operational audit trails and real-time shipment monitoring. This phase deploys three secure, non-editable listing views: `InTransitResource`, `StockMovementResource`, and `LossLedgerResource` with advanced aggregate summary footers and eager relationship loading to resolve N+1 overhead.

---

#### Requirements & Specs

##### 1. Virtual In-Transit Monitor (`app/Filament/Resources/InTransitResource.php`)

Provides logistics tracking of cargo dispatched but not yet received.

*   **Query Scoping & Eager Loading**:
    ```php
    public static function getEloquentQuery(): \Illuminate\Database\Eloquent\Builder
    {
        $user = auth()->user();
        return parent::getEloquentQuery()
            ->with(['requisition.fromWarehouse', 'requisition.toWarehouse', 'variant'])
            ->where('status', 'in_transit')
            ->when(! $user->isAdmin() && ! $user->isAuditor(), function ($query) use ($user) {
                // Restrict to shipments involving the worker's warehouse
                $warehouseIds = $user->warehouses->pluck('id');
                $query->whereHas('requisition', function ($q) use ($warehouseIds) {
                    $q->whereIn('from_warehouse_id', $warehouseIds)
                      ->orWhereIn('to_warehouse_id', $warehouseIds);
                });
            });
    }
    ```

*   **Table Configuration**:
    *   `requisition.reference_code`: Searchable reference string.
    *   `from`: Custom text column returning source warehouse.
    *   `to`: Custom text column returning destination warehouse.
    *   `variant.sku`: Standard SKU identifier.
    *   `dispatched_base_qty`: Number column representing expected base units.
    *   `dispatched_at`: Timestamp showing when the shipment departed.
    *   `elapsed_time`: Custom TextColumn calculating hours elapsed since departure:
        ```php
        Tables\Columns\TextColumn::make('dispatched_at')
            ->label('Elapsed Duration')
            ->formatStateUsing(fn ($state) => now()->diffInHours($state) . ' hours ago')
            ->color('warning'),
        ```

##### 2. Immutable Movement Ledger (`app/Filament/Resources/StockMovementResource.php`)

Provides an un-editable historical ledger record of every single stock adjustment or shipment.

*   **Scoping & Table Configuration**:
    *   Ensure all actions (`CreateAction`, `EditAction`, `DeleteAction`) are removed entirely.
    *   *Columns*:
        *   `created_at`: Sortable datetime showing exact entry timestamp.
        *   `variant.sku`: Product variant SKU.
        *   `warehouse.name`: Physical location where adjustment occurred.
        *   `type`: Colored badge representing transaction type:
            *   `receive` / `transfer_in` => `'success'` (green badge).
            *   `ship` / `transfer_out` => `'warning'` (orange badge).
            *   `adjustment` => `'info'` (blue badge).
            *   `loss` => `'danger'` (red badge).
        *   `quantity`: Base unit delta displaying signed integers (e.g. `+1,500` or `-500`).
        *   `reference_code`: Associated reference document identifier.
        *   `creator.name`: Operator user who authorized movement.

---

##### 3. Financial Loss Auditor (`app/Filament/Resources/LossLedgerResource.php`)

Monitors operational shrinkage, breakages, and transit variances.

*   **Query Scoping & Precision Summary Table**:
    *   *Columns*:
        *   `requisition.reference_code`: Requisition code link.
        *   `variant.sku`: Shipped SKU.
        *   `warehouse.name`: Branch bearing loss.
        *   `lost_base_qty` / `damaged_base_qty`: Quantities in Base Units.
        *   `unit_cost_price`: Dynamic display showing micro-unit base cost:
            ```php
            Tables\Columns\TextColumn::make('unit_cost_price')
                ->label('Cost (Base Unit)')
                ->money('USD', precision: 4), // Aligned with micro-precision decimal updates
            ```
        *   `total_financial_loss`: Renders calculated total loss amount with high decimal accuracy.
        *   `loss_category`: Select filter category.

*   **Aggregate Summarizer Footer**:
    Directly sum totals inside the footer to display high-level write-off value:
    ```php
    Tables\Columns\TextColumn::make('total_financial_loss')
        ->label('Total Monetary Loss')
        ->money('USD', precision: 4)
        ->summarize(
            Tables\Columns\Summarizers\Sum::make()
                ->label('Cumulative Write-offs')
                ->money('USD', precision: 4)
        )
    ```

#### Output Verification
*   Log in as an Auditor and access `/admin/loss-ledgers`.
*   Assert that you can view a summarized overview of loss metrics with 4-decimal place financial write-off figures displaying in the table columns and running summaries footer.
*   Assert that all edit, create, and delete operations are missing, ensuring ledger immutability.
