# Prompt 4 — InventoryService

Write an InventoryService class for Laravel 13. Requirements:
- recordMovement(productId, warehouseId, type, quantity, reference = null,
  relatedMovementId = null): creates a StockMovement row. quantity is signed
  (positive for in, negative for out). No separate inventory table — stock
  is always derived via SUM(quantity).
- ship(productId, warehouseId, quantity, reference = null): checks
  currentQuantity() first and throws an exception if insufficient stock,
  then calls recordMovement with a negative quantity. Wrap in DB::transaction.
- transfer(productId, fromWarehouseId, toWarehouseId, quantity, reference = null):
  creates a transfer_out movement at the source and a transfer_in movement at
  the destination, linked via related_movement_id, in a single DB transaction.
- currentQuantity(productId, warehouseId): returns SUM(quantity) for that pair.
- totalQuantity(productId): returns SUM(quantity) across all warehouses.

Put it in app/Services/InventoryService.php.
