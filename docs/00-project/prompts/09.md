## 📂 Phase 09: Printable Manifest Sheets (STN & Direct)

### Developer Instruction Prompt
Implement a robust **Stock Transfer Note (STN) Manifest System** to document dispatch logistics physically and digitally:

1. **Print Controller Route (`STNManifestController.php`)**:
   * Expose safe controller methods to compile print layouts for both requisitions (`print()`) and direct transfers (`printDirectTransfer()`).
   * Perform authorization checks to confirm the operator is assigned to one of the active warehouses before rendering.
   * Generate a **secure temporary signed URL route** valid for 30 days and compile it into an SVG QR code block utilizing `SimpleQRCode` (`QrCode::size(120)->generate($signedUrl)`).
2. **Clinical-Print Blade Templates (`stn-manifest.blade.php` & `direct-transfer-manifest.blade.php`)**:
   * Create a flat, high-contrast grid design styled specifically for thermal or standard printing hardware.
   * Use CSS print directives (`@media print`) to hide browser headers, footers, sidebars, and screen-only button controls.
   * Render complete transaction metadata, full line item details (using amber alerts for substituted variants), and embed the signed QR scan-code.
   * **Paper Backup Disclaimer**: Add explicit double-sign-off signature lines for both origin and destination managers, with a prominent footer disclaimer declaring that printed signatures are secondary backups and that system records remain the single source of truth.
3. **Print Header Actions**:
   * On the View pages, register a secondary header action `Print STN Manifest` that launches the print route in a new browser tab.
