# Prompt 9 — Scoping & Transfer Visibility

In my Laravel 13 + Filament v5 StockMovementResource, add role-based query
scoping: override getEloquentQuery() so that non-admin users only see
StockMovement rows where warehouse_id is in their assigned warehouses
(auth()->user()->warehouses). Admins see everything.

Also add a computed accessor on the StockMovement model called
counterpart_warehouse: for transfer_in/transfer_out rows, look up the paired
row via related_movement_id (or the reverse lookup where another row's
related_movement_id equals this row's id) and return that row's warehouse
name. Add this as a "From/To" column in the table for extra context on
transfers, so staff can see where stock came from or went to without
gaining access to that warehouse's full inventory.
