# Phase 09: Requisition Negotiation Loops & Counter-Offer Revision Infolists (v3.0)

## Objective
Build `RequisitionInfolist.php` and `RevisionsRelationManager.php` to display multi-stage counter-offer proposals, tracking original vs. negotiated substitute variants (`substitute_product_variant_id`).

---

## `app/Filament/Resources/TransferRequisitions/Infolists/RequisitionInfolist.php`

```php
namespace App\Filament\Resources\TransferRequisitions\Infolists;
a
use Filament\Infolists\Infolist;
use Filament\Infolists\Components\Grid;
use Filament\Infolists\Components\Section;
use Filament\Infolists\Components\TextEntry;
use Filament\Infolists\Components\RepeatableEntry;

class RequisitionInfolist
{
    public static function make(Infolist $infolist): Infolist
    {
        return $infolist
            ->schema([
                Grid::make(3)
                    ->schema([
                        Section::make('REQUISITION PROFILE')
                            ->schema([
                                TextEntry::make('reference_code')->bold()->copyable(),
                                TextEntry::make('status')->badge(),
                                TextEntry::make('fromWarehouse.name')->label('ORIGIN'),
                                TextEntry::make('toWarehouse.name')->label('DESTINATION'),
                            ])->columnSpan(2),

                        Section::make('SIGN-OFFS')
                            ->schema([
                                TextEntry::make('requestedBy.name')->label('REQUESTED BY'),
                                TextEntry::make('approvedBy.name')->label('APPROVED BY'),
                                TextEntry::make('dispatchedBy.name')->label('DISPATCHED BY'),
                            ])->columnSpan(1),

                        Section::make('MATERIAL MANIFEST ITEMS')
                            ->schema([
                                RepeatableEntry::make('items')
                                    ->schema([
                                        TextEntry::make('productVariant.sku')->label('ORIGINAL VARIANT')->bold(),
                                        TextEntry::make('substituteProductVariant.sku')->label('PROPOSED SUBSTITUTE')->badge()->color('warning')->placeholder('No Swap'),
                                        TextEntry::make('requested_qty')->state(fn ($record) => "{$record->requested_qty} {$record->requested_unit_name}"),
                                        TextEntry::make('approved_qty')->state(fn ($record) => $record->approved_qty ? "{$record->approved_qty} {$record->approved_unit_name}" : 'Pending'),
                                    ])->columns(4),
                            ])->columnSpanFull(),
                    ]),
            ]);
    }
}
```
