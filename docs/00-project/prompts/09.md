### Phase 09: Scan-to-Receive Modal & Loss Ledger Integration

#### Objective
Implement the FilamentScan-to-Receive modal action. This interface is triggered automatically by URL routing queries (`?scan=1`), handles incoming physical counts, highlights negotiated substitute variants dynamically, validates counts against dispatched quantities, and registers discrepancies into the permanent financial `LossLedger`.

---

#### Requirements & Specs

##### 1. Mounting Query Listener (`app/Filament/Resources/TransferRequisitionResource/Pages/ViewTransferRequisition.php`)

Auto-launches the scanning intake workflow if scanned from a physical QR code containing the `scan=1` url parameter:

```php
public function mount($record): void
{
    parent::mount($record);

    // Auto-launch scanning modal on scanning trigger
    if (request()->query('scan') == 1 && $this->record->status === 'dispatched') {
        $this->js('$wire.mountAction("scanToReceiveAction")');
    }
}
```

---

##### 2. Scan-to-Receive Modal Component Form (`app/Filament/Resources/TransferRequisitionResource/Pages/ViewTransferRequisition.php`)

Construct the modal action ensuring clear visual guidance and numerical validation constraints:

```php
protected function getScanToReceiveAction(): Actions\Action
{
    return Actions\Action::make('scanToReceiveAction')
        ->label('Reconcile & Receive Shipment')
        ->icon('heroicon-o-qrcode')
        ->color('success')
        ->visible(fn ($record) => $record->status === 'dispatched')
        ->form([
            Forms\Components\Repeater::make('received_items')
                ->schema([
                    // Guardrail 1: Highlight Substitute Variant Swapping
                    Forms\Components\Placeholder::make('variant_display')
                        ->label('Product Variant')
                        ->content(function ($record, Forms\Get $get) {
                            $item = \App\Models\TransferRequisitionItem::with(['variant', 'substituteVariant'])->find($get('item_id'));
                            if (! $item) return 'Unknown Variant';

                            if ($item->substitute_variant_id) {
                                return "⚠️ Original SKU: {$item->variant->sku} → NEGOTIATED SUBSTITUTE SKU: {$item->substituteVariant->sku} ({$item->substituteVariant->name})";
                            }
                            return "SKU: {$item->variant->sku} ({$item->variant->name})";
                        }),

                    Forms\Components\Hidden::make('item_id'),

                    Forms\Components\Placeholder::make('shipped_qty_display')
                        ->label('Expected (In-Transit)')
                        ->content(fn (Forms\Get $get) => number_format($get('expected_qty_uom')) . ' Units'),

                    Forms\Components\TextInput::make('good_qty')
                        ->label('Good Units Received')
                        ->numeric()
                        ->default(0)
                        ->required()
                        ->minValue(0)
                        ->reactive()
                        ->afterStateUpdated(fn ($state, Forms\Set $set, Forms\Get $get) => $this->validateIntakeTotals($set, $get)),

                    Forms\Components\TextInput::make('damaged_qty')
                        ->label('Damaged Units Received')
                        ->numeric()
                        ->default(0)
                        ->required()
                        ->minValue(0)
                        ->reactive()
                        ->afterStateUpdated(fn ($state, Forms\Set $set, Forms\Get $get) => $this->validateIntakeTotals($set, $get)),

                    Forms\Components\Placeholder::make('lost_qty_display')
                        ->label('Computed Missing/Lost Units')
                        ->content(fn (Forms\Get $get) => number_format($get('lost_qty') ?? 0) . ' Units'),

                    // Category dropdown for variance classifications
                    Forms\Components\Select::make('loss_category')
                        ->label('Reason for Shortage / Damage')
                        ->placeholder('Select a category...')
                        ->options([
                            'Damaged in Transit' => 'Damaged in Transit',
                            'Short Shipment / Missing Units' => 'Short Shipment / Missing Units',
                            'Spoiled / Temperature Exceeded' => 'Spoiled / Temperature Exceeded',
                            'Pilferage' => 'Pilferage / Theft',
                        ])
                        ->required(fn (Forms\Get $get) => ((int)$get('lost_qty') > 0 || (int)$get('damaged_qty') > 0))
                        ->visible(fn (Forms\Get $get) => ((int)$get('lost_qty') > 0 || (int)$get('damaged_qty') > 0)),
                ])
                ->addable(false)
                ->deletable(false)
        ])
        ->fillForm(function (\App\Models\TransferRequisition $record) {
            // Pre-fill fields matching current shipping states
            return [
                'received_items' => $record->items->map(fn ($item) => [
                    'item_id' => $item->id,
                    'expected_qty_uom' => $item->shipped_base_qty / ($item->approved_unit_ratio ?? $item->requested_unit_ratio),
                    'good_qty' => $item->shipped_base_qty / ($item->approved_unit_ratio ?? $item->requested_unit_ratio),
                    'damaged_qty' => 0,
                    'lost_qty' => 0,
                ])->toArray()
            ];
        })
        ->action(function (\App\Models\TransferRequisition $record, array $data, \App\Services\InventoryService $service) {
            // Re-key form dataset to match standard service parameters
            $mappedData = [];
            foreach ($data['received_items'] as $entry) {
                $mappedData[$entry['item_id']] = [
                    'good_qty' => (int)$entry['good_qty'],
                    'damaged_qty' => (int)$entry['damaged_qty'],
                    'loss_category' => $entry['loss_category'] ?? null,
                ];
            }

            // Execute secure receipt transaction
            $service->scanToReceive($record->id, $mappedData);

            \Filament\Notifications\Notification::make()
                ->title('Inventory Received successfully')
                ->success()
                ->send();
        });
}

/**
 * Validator helper verifying that input tallies do not exceed expected totals.
 */
protected function validateIntakeTotals(Forms\Set $set, Forms\Get $get): void
{
    $expected = (int)$get('expected_qty_uom');
    $good = (int)$get('good_qty');
    $damaged = (int)$get('damaged_qty');

    if (($good + $damaged) > $expected) {
        $set('good_qty', $expected);
        $set('damaged_qty', 0);
        $set('lost_qty', 0);
        
        \Filament\Notifications\Notification::make()
            ->title('Invalid Entry')
            ->body('Combined good and damaged quantities cannot exceed the original dispatched cargo quantity.')
            ->warning()
            ->send();
    } else {
        $set('lost_qty', $expected - ($good + $damaged));
    }
}
```
