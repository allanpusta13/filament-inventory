# Phase 06: Warehouse Location Resource & Slide-Over Manual Note Adjusters (v3.0)

## Objective
Build `WarehouseResource`. Attach inline slide-over table action `manualStockAdjustment` to capture signed movement deltas with a mandatory 15-character audit reason validator. Attach `WarehouseStocksRelationManager` displaying pure derived stock.

---

## `app/Filament/Resources/Warehouses/Tables/WarehousesTable.php`

```php
namespace App\Filament\Resources\Warehouses\Tables;

use App\Models\Warehouse;
use App\Services\InventoryService;
use Filament\Tables\Table;
use Filament\Tables\Columns\TextColumn;
use Filament\Tables\Columns\IconColumn;
use Filament\Tables\Actions\EditAction;
use Filament\Tables\Actions\Action;
use Filament\Forms\Components\Select;
use Filament\Forms\Components\TextInput;
use Filament\Support\Icons\Heroicon;

class WarehousesTable
{
    public static function make(Table $table): Table
    {
        return $table
            ->columns([
                TextColumn::make('code')->label('CODE')->bold()->searchable(),
                TextColumn::make('name')->label('WAREHOUSE NAME')->searchable(),
                IconColumn::make('is_active')->label('ROUTING ACTIVE')->boolean(),
            ])
            ->actions([
                EditAction::make(),
                Action::make('manualStockAdjustment')
                    ->label('Record Adjustment')
                    ->slideOver()
                    ->icon(Heroicon::AdjustmentsHorizontal)
                    ->form([
                        Select::make('product_variant_id')
                            ->label('PRODUCT VARIANT')
                            ->relationship('productVariant', 'sku')
                            ->required()
                            ->searchable(),
                        TextInput::make('quantity')
                            ->label('BASE UNITS ADJUSTMENT DELTA')
                            ->numeric()
                            ->required(),
                        TextInput::make('audit_reason')
                            ->label('AUDIT COMPLIANCE REASON NOTES')
                            ->required()
                            ->string()
                            ->minLength(15)
                            ->regex('/^(?!(.)\1+$)(?!\b(test|dummy|notes|adjust|none)\b)/i')
                            ->placeholder('Provide a clear, descriptive audit explanation (min. 15 characters)...'),
                    ])
                    ->action(function (Warehouse $record, array $data, InventoryService $service) {
                        $service->recordMovement(
                            productVariantId: $data['product_variant_id'],
                            warehouseId: $record->id,
                            type: 'adjustment',
                            baseQuantity: $data['quantity'],
                            unitName: 'Base Unit',
                            unitRatio: 1,
                            referenceType: Warehouse::class,
                            referenceId: $record->id,
                            referenceCode: 'MANUAL-ADJ-' . strtoupper(uniqid())
                        );
                    }),
            ]);
    }
}
```
