# Prompt 6 — Warehouse Resource

Generate a Filament v5 resource for the Warehouse model (Laravel 13, Filament 5
file structure). Fields: name, location, is_active. This resource should
only be visible/accessible to admins — override canViewAny() (and canCreate/
canEdit/canDelete) to check auth()->user()->isAdmin(). Also add a relation
manager or simple multi-select on this resource (or on a UserResource) so an
admin can assign which users/staff belong to which warehouse via the
user_warehouse pivot.
