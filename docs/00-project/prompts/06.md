### Phase 06: Warehouse & Pricing Matrix Resources

#### Objective
Build the management interfaces for local distribution hubs (`WarehouseResource`) and custom, location/packaging pricing matrices (`ProductPriceResource`). Embed rigorous input restrictions on the manual stock adjustment audit trail, and configure pricing forms to support high sub-cent precision.

---

#### Requirements & Specs

##### 1. Warehouse Resource & Manual Stock Overrides (`app/Filament/Resources/WarehouseResource.php`)

*   **Standard Form Fields**:
    *   `code`: Unique text label (e.g., `'WH-MNL'`).
    *   `name`: Administrative branch name (e.g., `'Main Manila Central Hub'`).
    *   `location`: Detailed physical address text area.
    *   `is_active`: Toggle switch defining state.

*   **Guardrail 9: Audited Manual Stock Adjustments Action**:
    To log stock levels manually for correction, configure a custom, slide-over action directly inside the warehouse listings table or details view:
    ```php
    Tables\Actions\Action::make('adjustStock')
        ->label('Adjust Stock Level')
        ->icon('heroicon-o-adjustments-horizontal')
        ->slideOver()
        ->form([
            Forms\Components\Select::make('variant_id')
                ->label('Select Product Variant')
                ->options(\App\Models\ProductVariant::pluck('sku', 'id'))
                ->required()
                ->searchable(),
            Forms\Components\TextInput::make('adjustment_quantity')
                ->label('Adjustment delta (Base Units)')
                ->helperText('Use positive integer for gains, negative integer for losses.')
                ->integer()
                ->required(),
            Forms\Components\Textarea::make('audit_reason')
                ->label('Mandatory Audit Note')
                ->placeholder('Enter detailed reason for manual override (minimum 15 characters)...')
                ->required()
                ->minLength(15) // Enforces a robust descriptive minimum length
                ->rule(function () {
                    return function (string $attribute, $value, $fail) {
                        // Prevent repetitive characters (e.g. "............") or simple dummy inputs (e.g. "manual override test")
                        if (preg_match('/^(.)\1+$/', trim($value)) || in_array(strtolower(trim($value)), ['manual override', 'stock adjustment', 'test notes', 'temporary adjustment'])) {
                            $fail('The audit reason must contain a genuine, non-repetitive descriptive explanation.');
                        }
                    };
                }),
        ])
        ->action(function (\App\Models\Warehouse $record, array $data, \App\Services\InventoryService $service) {
            // Trigger the atomic service transactional ledger write-off
            $service->recordMovement(
                variantId: $data['variant_id'],
                warehouseId: $record->id,
                type: 'adjustment',
                baseQuantity: $data['adjustment_quantity'],
                unitName: 'Base Unit',
                unitRatio: 1,
                referenceType: 'ManualAdjustment',
                referenceId: $record->id,
                referenceCode: 'ADJ-' . now()->format('Ymd-His'),
                relatedMovementId: null
            );
        });
    ```

##### 2. Pricing Matrix Resource (`app/Filament/Resources/ProductPriceResource.php`)

Supports localized cost margins and packaged pricing profiles.

*   **Precision Schema Matching Form Fields**:
    *   `variant_id`: Select option searching active `ProductVariant` records.
    *   `warehouse_id`: Select option linking `Warehouse` records (nullable; `null` denotes a global default price).
    *   `unit_name`: Dynamic selection querying the variant's base unit name or conversion unit labels.
    *   `price_type`: Dropdown with enum options: `cost`, `sale`.
    *   `price`: Decimal text input matching sub-cent precision boundaries:
        ```php
        Forms\Components\TextInput::make('price')
            ->label('Custom Price Amount')
            ->numeric()
            ->required()
            ->step('0.0001') // Permits micro-unit overrides like $0.0125
            ->prefix('$')
            ->minValue(0),
        ```

*   **Data Aggregations (Table Layout)**:
    Eager load variant records to bypass list N+1 query loops:
    ```php
    public static function table(Table $table): Table
    {
        return $table
            ->query(\App\Models\ProductPrice::with(['variant', 'warehouse']))
            ->columns([
                Tables\Columns\TextColumn::make('variant.sku')->label('Variant SKU')->bold()->searchable(),
                Tables\Columns\TextColumn::make('warehouse.name')->label('Warehouse Location')->placeholder('Global Default'),
                Tables\Columns\TextColumn::make('unit_name')->label('Unit Level'),
                Tables\Columns\TextColumn::make('price_type')->badge()->color(fn ($state) => $state === 'sale' ? 'success' : 'gray'),
                Tables\Columns\TextColumn::make('price')->money('USD', divideBy: 1, precision: 4), // Renders with 4 decimal places
            ]);
    }
    ```
