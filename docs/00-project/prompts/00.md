# Phase 00: Environment Setup, Tooling & 12 Architectural Guardrails (v3.0)

## 1. Objective
Initialize the Laravel 13 framework, install FilamentPHP v5, Livewire v4, Tailwind CSS v4, SimpleQRCode, Laravel DomPDF, Pest PHP, and Laravel Pint. Establish the **12 Non-Negotiable Architectural Guardrails** that must govern all subsequent execution phases.

---

## 2. Mandatory Architectural Guardrails (Phases 01–16)

1. **Micro-Pricing Precision (`decimal:15,4`)**:
   All database columns for cost prices, selling prices, unit price overrides, and financial write-offs must be created as `decimal(15,4)` with `0.0000` default values. Currency rounding is restricted strictly to UI formatting.

2. **Pure Derived Stock of Truth (No Cached Balance Tables)**:
   Never store physical stock balances or reservation counts in physical database columns (e.g. `warehouse_stock`). Physical on-hand stock (`onHandQuantity()`), active reservations (`reservedQuantity()`), and available balances (`availableQuantity()`) are computed dynamically at query-time from `stock_movements` and active requisitions.

3. **Ledger Immutability**:
   `stock_movements`, `loss_ledgers`, and `transfer_requisition_item_revisions` are append-only. Rows must never be updated or deleted. Corrections require balanced, reversing movement entries.

4. **Variant-Level SKUs & Safety Thresholds**:
   `sku`, `barcode`, `base_unit_name`, `cost_price`, `sale_price`, and `reorder_point` reside exclusively on `product_variants`. Parent `products` act purely as family grouping containers (`name`, `category`).

5. **Explicit Foreign Key Contracts**:
   All foreign keys follow table-bound names: `product_variant_id`, `transfer_requisition_id`, `transfer_requisition_item_id`, `substitute_product_variant_id`.

6. **Modal-First Form Transitions (< 8 Inputs Rule)**:
   Forms with fewer than 8 input fields (*Variants, Unit Conversions, Warehouses, Users, Manual Adjustments*) run inside slide-overs (`slideOver()`) or table modals (`modal()`). All modals enforce `->closeModalByClickingAway(false)` to prevent losing scan data.

7. **Positive Quantities Enforcement**:
   Forms, APIs, and services must enforce validation assertions ensuring that requested and transferred quantities are positive integers greater than zero (`minValue(1)`).

8. **Scanned Receipt Loss Integrity & Omitted Items**:
   If an expected dispatched item is omitted from a physical intake payload, it must be logged as `0` received, calculating a 100% variance loss write-off on `loss_ledgers` at historic unit cost price.

9. **Temporary Signed QR Route Error Interception**:
   STN QR codes encode temporary 30-day signed URLs. Routing handlers intercept invalid/expired signatures or unauthorized warehouse access and redirect users to the dashboard with an explicit warning toast instead of rendering raw 403 pages.

10. **High-Performance Widget Caching (300s TTL)**:
    Dashboard widget aggregations are wrapped in cache tags (`Cache::remember()`) with a 300-second expiration scope, keyed by active warehouse filters.

11. **Multi-Language Internationalization (Zero Hardcoding)**:
    100% of user-facing UI labels are loaded from translation catalogs (`lang/{locale}/`) and formatted dynamically using `\Illuminate\Support\Str::upper(__('filename.key'))`.

12. **CI/CD Testing Database Isolation**:
    Unit/Feature Pest tests execute against an in-memory SQLite database (`:memory:`). Sequential Playwright E2E browser tests execute against an isolated PostgreSQL container.
