### Phase 12: Security Hardening & Query Performance Optimization

#### Objective
Secure and optimize the inventory platform. Audit and resolve N+1 query patterns across listing views, implement strict database index optimization on multi-column foreign keys, apply secure HTTP headers, and configure endpoint-level rate limiters to defend against brute-force or malicious scanning.

---

#### Requirements & Specs

##### 1. Database Indexing Scheme Audit
Ensure that migration files define indexes on columns involved in search operations, group-by filters, or pessimistic locks to maintain query times under **200ms** even when tables hold over 100,000 records:

*   **`warehouse_stock`**:
    *   Compound unique index: `$table->unique(['variant_id', 'warehouse_id']);` *(Acts as the primary anchor for pessimistic locking and prevents duplicate rows)*.
*   **`stock_movements`**:
    *   Compound index: `$table->index(['variant_id', 'warehouse_id']);`
    *   Indexed creation timestamp: `$table->index('created_at');`
    *   Polymorphic index: `$table->index(['reference_type', 'reference_id']);`
*   **`transfer_requisitions`**:
    *   Unique index: `$table->unique('reference_code');`
    *   Foreign key indices: `from_warehouse_id`, `to_warehouse_id`.
*   **`loss_ledger`**:
    *   Foreign key indices: `variant_id`, `warehouse_id`.

---

##### 2. N+1 Query Auditing & Eager Loading

Eliminate database round-trip overhead on Filament index pages. Register relationships inside listing queries to guarantee single-query rendering:

*   **`ProductResource`**: Eager load `variants` when loading catalog layouts.
*   **`TransferRequisitionResource`**: Eager load `fromWarehouse`, `toWarehouse`, `requestedBy`, and `items`.
*   **`LossLedgerResource`**: Eager load `requisition`, `variant`, and `warehouse`.
*   **`StockMovementResource`**: Eager load `variant`, `warehouse`, and `creator`.

*   *Verification Script / Debugging*: Install `barryvdh/laravel-debugbar` or use Laravel Telescope in local staging. Verify that loading the `StockMovement` index view registers **zero** duplicated queries.

---

##### 3. Route Security Throttling & HTTP Headers

*   **STN Scan Throttling** (`app/Providers/RouteServiceProvider.php`):
    Enforce a maximum limit of 20 scans per minute per IP address. When exceeded, return a graceful HTTP 429 error displaying a Filament notification warning rather than a raw exception page.
    ```php
    use Illuminate\Cache\RateLimiting\Limit;
    use Illuminate\Support\Facades\RateLimiter;

    RateLimiter::for('scans', function (Request $request) {
        return Limit::perMinute(20)->by($request->user()?->id ?: $request->ip());
    });
    ```

*   **Secure HTTP Headers Middleware** (`app/Http/Middleware/ApplySecurityHeaders.php`):
    Create a global middleware class appending industry-standard browser security policies to all responses:
    ```php
    namespace App\Http\Middleware;

    use Closure;
    use Illuminate\Http\Request;

    class ApplySecurityHeaders
    {
        public function handle(Request $request, Closure $next)
        {
            $response = $next($request);

            $response->headers->set('X-Frame-Options', 'DENY');
            $response->headers->set('X-Content-Type-Options', 'nosniff');
            $response->headers->set('X-XSS-Protection', '1; mode=block');
            $response->headers->set('Referrer-Policy', 'strict-origin-when-cross-origin');
            $response->headers->set('Content-Security-Policy', "default-src 'self'; script-src 'self' 'unsafe-inline' 'unsafe-eval'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; frame-ancestors 'none';");

            return $response;
        }
    }
    ```
