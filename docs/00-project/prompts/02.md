### Phase 02: Eloquent Models & Relationship Mapping

#### Objective
Generate Eloquent models for every database entity with strict mass-assignment protection (`$fillable`), attribute casting for micro-unit pricing precision, custom domain accessors, relationship methods, and lifecycle observers for safety during soft deletes.

---

#### Requirements & Specs

    *   *Traits*: `Illuminate\Database\Eloquent\SoftDeletes`, `Illuminate\Database\Eloquent\Factories\HasFactory`
    *   *Properties*: `$fillable = ['sku', 'name', 'category', 'reorder_point']`
    *   *Relations*: `variants()` (HasMany → `ProductVariant`)

*   **ProductVariant** (`app/Models/ProductVariant.php`):
    *   *Traits*: `Illuminate\Database\Eloquent\SoftDeletes`, `Illuminate\Database\Eloquent\Factories\HasFactory`

    *   *Casts*:

        *   `images` => `json`

        *   `prices()` (HasMany → `ProductPrice`)

        *   `movements()` (HasMany → `StockMovement`)
    *   *Domain Accessor*: `getAvailableQuantityForWarehouse(int $warehouseId): int`

##### 2. Soft-Delete Safety Observer (Crucial Concurrency Guard)

To prevent stock reservation leaks when a confirmed or draft transfer is soft-deleted, register a boot observer on the `TransferRequisition` model.

*   *Location*: `app/Models/TransferRequisition.php` (inside `booted` method or standalone Observer class)
*   *Rules*:
    1.  When a `TransferRequisition` is **deleting** (soft-deleting):
        *   If the requisition holds a status of `'confirmed'`, run a database transaction to return locked reservations:
            *   Acquire pessimistic locks (`lockForUpdate()`) on all associated `WarehouseStock` rows at the origin (`from_warehouse_id`).
            *   Decrement the `reserved_quantity` by each item's `$item->approved_base_qty ?? $item->requested_base_qty` value.
            *   Save the stock rows.
        *   If the requisition holds an active `'dispatched'` status, block deletion entirely and throw an operational exception—dispatched cargo cannot be deleted until receiving reconciles transit records or a reversal is formally executed.

```php
protected static function booted()
{
    static::deleting(function (TransferRequisition $requisition) {
        if ($requisition->status === 'dispatched') {
            throw new \Exception("Cannot delete a requisition that is currently in transit (Dispatched status).");
        }

        if ($requisition->status === 'confirmed') {
            \Illuminate\Support\Facades\DB::transaction(function () use ($requisition) {
                foreach ($requisition->items as $item) {
                    $stock = \App\Models\WarehouseStock::where('variant_id', $item->variant_id)
                        ->where('warehouse_id', $requisition->from_warehouse_id)
                        ->lockForUpdate()
                        ->first();

                    if ($stock) {
                        $releaseQty = $item->approved_base_qty ?? $item->requested_base_qty;
                        $stock->reserved_quantity = max(0, $stock->reserved_quantity - $releaseQty);
                        $stock->save();
                    }
                }
            });
        }
    });
}
```
