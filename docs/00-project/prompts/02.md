# Prompt 2 — Migrations & Models

Using this schema, generate the Laravel migrations and Eloquent models:

- products: sku (unique), name, category (nullable), unit (default 'each'),
  reorder_point (default 0)
- warehouses: name, location (nullable), is_active (default true)
- stock_movements: product_id FK, warehouse_id FK, type (enum: receive, ship,
  transfer_out, transfer_in, adjustment), quantity (signed integer),
  related_movement_id (nullable FK to stock_movements), reference (nullable),
  created_by (nullable FK to users). Add an index on (product_id, warehouse_id).
- users: add a 'role' column, default 'warehouse_staff'
- user_warehouse: pivot table (user_id, warehouse_id)

Also write the Eloquent models with relationships:
Product hasMany StockMovement, Warehouse hasMany StockMovement (via warehouse_id),
User belongsToMany Warehouse, StockMovement belongsTo Product/Warehouse/related self.

Use Laravel 13's #[Fillable] attribute instead of a $fillable array property.
