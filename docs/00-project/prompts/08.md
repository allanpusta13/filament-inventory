## 📂 Phase 08: Dialog-Based 3-Step Wizards with Real-Time Review

### Developer Instruction Prompt
Configure the creation wizards for **Transfer Requisitions** and **Direct Transfers** as fast, in-page **3xl-width Dialog Modals** mapped to header actions on list views. Enforce `->closeModalByClickingAway(false)` to prevent data loss:

1. **Transfer Requisitions Wizard (`Pages/ListTransferRequisitions.php`)**:
   * **Step 1: Routing Pathways**: Set origin and destination warehouses, preventing self-transfers.
   * **Step 2: Material Manifest**: Render a multi-row repeater to input variant SKUs, packaging conversions, ratios, and order quantities (positive integers only).
   * **Step 3: Review & Verify**: Generate a real-time read-only HTML summary table displaying selected locations, product SKUs, packaging multipliers, and total computed base quantities before submission.
2. **Direct Transfers Wizard (`Pages/ListDirectTransfers.php`)**:
   * **Step 1: Location Mapping**: Set sending and receiving locations.
   * **Step 2: Stock Allocation**: Set selected variant, positive transfer quantity, and a mandatory 15-character audit compliance note.
   * **Step 3: Review & Verify**: Display a read-only visual manifest summarizing the warehouses, variant, transfer volume, and italicized notes. Clicking "Execute Now" calls `InventoryService::executeDirectTransfer()`.
