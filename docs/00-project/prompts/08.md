# Prompt 8 — Custom Actions (Receive / Ship / Transfer / Adjustment)

On my Filament v5 StockMovementResource (Laravel 13), add four header actions
on the table page, each opening its own small form and calling my
InventoryService (app/Services/InventoryService.php):

1. "Receive Stock" — form: product_id (select), warehouse_id (select),
   quantity (numeric), reference (text, optional). Calls
   InventoryService::recordMovement(..., type: 'receive', positive quantity).
2. "Ship Stock" — same fields. Calls InventoryService::ship() and catches
   the insufficient-stock exception, showing a Filament notification on failure.
3. "Transfer Stock" — form: product_id, from_warehouse_id, to_warehouse_id,
   quantity, reference. Calls InventoryService::transfer().
4. "Adjustment" — form: product_id, warehouse_id, quantity (can be negative
   or positive), reference (required, used as the reason). Calls
   recordMovement with type 'adjustment'.

For all four, the warehouse_id / from_warehouse_id select options should be
restricted to auth()->user()->warehouses if the user is not an admin
(admins see all warehouses). For "Transfer," the from_warehouse select is
restricted this way but the to_warehouse select shows all active warehouses
regardless of role.
