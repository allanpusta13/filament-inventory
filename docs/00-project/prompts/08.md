### Phase 08: Printable STN PDF Manifest & Signed QR Routing

#### Objective
Build the physical-to-digital integration layer that generates a printable PDF Stock Transfer Note (STN) manifest. The manifest features a dynamically drawn QR code encoding a secure, temporary signed URL valid for 30 days. Implement rate-limited routing and graceful error redirection to bypass raw, unhandled Laravel 403 pages when scanning expired signatures or if scanned by unauthorized staff.

---

#### Requirements & Specs

##### 1. Secure Signed Routing (`routes/web.php`)

To prevent raw `403 Invalid Signature` error pages when a physical STN QR code has expired or holds an invalid URL signature, customize signature handling within the route definition:

```php
use App\Filament\Resources\TransferRequisitionResource;
use Illuminate\Support\Facades\Route;
use Illuminate\Support\Facades\RateLimiter;
use Illuminate\Http\Request;

Route::middleware(['auth'])->group(function () {
    
    // Guardrail 7: Rate-limited signed QR scanning route with graceful redirection
    Route::get('/transfers/scan/{transferRequisition}', function (Request $request, \App\Models\TransferRequisition $transferRequisition) {
        
        // Assert signature validity manually to avoid abrupt aborts
        if (! $request->hasValidSignature()) {
            // Flash a dynamic Filament notice to the session
            session()->flash('notification', [
                'title' => 'Signature Expired or Invalid',
                'body' => 'The scanned physical Stock Transfer Note is older than 30 days or has been modified. Please generate a fresh manifest.',
                'type' => 'danger',
            ]);

            return redirect()->route('filament.admin.pages.dashboard');
        }

        // Guardrail 6: Scoped Access Authorization check
        $user = auth()->user();
        if (! $user->hasAccessToWarehouse($transferRequisition->to_warehouse_id) && 
            ! $user->hasAccessToWarehouse($transferRequisition->from_warehouse_id)) {
            
            session()->flash('notification', [
                'title' => 'Access Denied',
                'body' => 'You are not assigned to the origin or receiving warehouse linked to this transfer requisition.',
                'type' => 'warning',
            ]);

            return redirect()->route('filament.admin.pages.dashboard');
        }

        // Valid and authorized: Redirect to view details and launch intake modal automatically
        return redirect(
            TransferRequisitionResource::getUrl('view', [
                'record' => $transferRequisition->id,
                'scan' => 1,
            ])
        );
    })
    ->name('stn.scan')
    ->middleware('throttle:scans'); // Configured in RateLimiterServiceProvider
});
```

*   **Rate Limiter Registration** (`app/Providers/RouteServiceProvider.php` or `AppServiceProvider`):
    ```php
    RateLimiter::for('scans', function (Request $request) {
        return Limit::perMinute(20)->by($request->user()?->id ?: $request->ip());
    });
    ```

##### 2. PDF Document Layout & QR Injection (`app/Actions/GenerateSTNManifest.php`)

Draws the official physical document. The PDF consists of a structured summary header, a high-density, print-ready grid, and an embedded SVG QR block.

*   **Signed URL Generation**:
    ```php
    use Illuminate\Support\Facades\URL;
    use SimpleSoftwareIO\QrCode\Facades\QrCode;

    // Generate a secure 30-day cryptographically-signed access path
    $scanUrl = URL::temporarySignedRoute(
        'stn.scan',
        now()->addDays(30),
        ['transferRequisition' => $requisition->id]
    );

    // Render raw SVG QR code representing the secure entry path
    $qrCodeSvg = QrCode::size(140)
        ->errorCorrection('H')
        ->generate($scanUrl);
    ```

*   **Printable Blade Layout** (`resources/views/pdf/stn-manifest.blade.php`):
    *   Include a high-contrast CSS design utilizing absolute grid formatting for optimal print rendering.
    *   *Document Header*: Displays unique Reference Code, Origin Warehouse name and code, Destination Warehouse name, Dispatch timestamp, and the dynamic QR Code SVG element.
    *   *Shipping Grid*: Renders itemized tables outlining Variant SKU, Name, Approved Shipping Unit name, Unit quantity, and the dynamic Calculated Base unit count. Include signing fields at the footer for both Dispatching and Receiving managers.

##### 3. View-Page Print Action (`app/Filament/Resources/TransferRequisitionResource/Pages/ViewTransferRequisition.php`)

Add an action on the Filament View page to fetch and stream the PDF output:

```php
protected function getHeaderActions(): array
{
    return [
        Actions\Action::make('printSTN')
            ->label('Download STN PDF')
            ->icon('heroicon-o-document-arrow-down')
            ->color('gray')
            ->visible(fn ($record) => in_array($record->status, ['dispatched', 'partially_received', 'completed', 'closed_with_loss']))
            ->action(function (\App\Models\TransferRequisition $record) {
                // Compile Blade template and stream file stream
                $pdf = \Barryvdh\DomPDF\Facade\Pdf::loadView('pdf.stn-manifest', [
                    'requisition' => $record->load('items.variant')
                ]);
                
                return response()->streamDownload(
                    fn () => print($pdf->output()),
                    "STN-{$record->reference_code}.pdf"
                );
            }),
    ];
}
```
