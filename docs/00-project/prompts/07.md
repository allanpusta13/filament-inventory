## 📂 Phase 07: User Directory & Pivot-Linked Warehouses

### Developer Instruction Prompt
Generate the Filament v5 **`UserResource`** and locate it inside `app/Filament/Resources/Users/`. Decouple all schemas and tables:

1. **`Schemas/UserForm.php`**:
   * Uses the v5 `Schema::configure()` API.
   * Captures credentials, user role (using dropdown options populated from our `UserRole` Enum class), and displays a multiple-selection checkbox map to authorize access to specific warehouses.
2. **`Tables/UsersTable.php`**:
   * Displays users and their roles, color-coding role badges dynamically via the enum helper (`$state->badgeColor()`), highlighting administrative profiles in high-contrast red to indicate system risk.
3. **`RelationManagers/WarehousesRelationManager.php`**:
   * Coordinates linking users to warehouses via the `user_warehouse` pivot table.
