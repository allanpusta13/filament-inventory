# Phase 07: User Directory Resource & Pivot-Linked Warehouse Scoping (v3.0)

## Objective
Build `UserResource`. Implement role selection mapped to `UserRole` Enum, and attach `WarehousesRelationManager` to link physical warehouse site assignments through the `user_warehouse` pivot table.

---

## `app/Filament/Resources/Users/Schemas/UserForm.php`

```php
namespace App\Filament\Resources\Users\Schemas;

use Filament\Schemas\Schema;
use Filament\Schemas\Components\Section;
use Filament\Forms\Components\TextInput;
use Filament\Forms\Components\Select;
use App\Enums\UserRole;
use Filament\Support\Icons\Heroicon;

class UserForm
{
    public static function configure(Schema $schema): Schema
    {
        return $schema->components([
            Section::make('USER CREDENTIALS & ACCESS SCOPE')
                ->icon(Heroicon::User)
                ->columns(2)
                ->schema([
                    TextInput::make('name')->label('USER NAME')->required(),
                    TextInput::make('email')->label('EMAIL ADDRESS')->email()->required(),
                    TextInput::make('password')->label('PASSWORD')->password()->dehydrated(fn ($state) => filled($state)),
                    Select::make('role')
                        ->label('SYSTEM ACCESS ROLE')
                        ->options(UserRole::class)
                        ->required(),
                    Select::make('warehouses')
                        ->label('AUTHORIZED PHYSICAL WAREHOUSES')
                        ->multiple()
                        ->relationship('warehouses', 'name'),
                ]),
        ]);
    }
}
```
