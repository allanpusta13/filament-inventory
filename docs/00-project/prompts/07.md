# Prompt 7 — Stock Movement Resource (base)

Generate a Filament v5 resource for the StockMovement model (Laravel 13,
Filament 5 file structure: Schemas/StockMovementForm.php,
Tables/StockMovementsTable.php). Table columns: product.name, warehouse.name,
type (as a colored badge — green for receive/transfer_in, red for
ship/transfer_out, yellow for adjustment), quantity, reference, created_at.
This table is read-only: disable the default edit and delete actions/pages,
since these are audit log rows that should never be manually edited.
Add a SelectFilter for direction: Incoming (receive, transfer_in) vs
Outgoing (ship, transfer_out).
