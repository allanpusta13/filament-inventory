### Phase 07: Inter-Warehouse Requisition Wizard & Negotiation UI

#### Objective
Design and implement the administrative `TransferRequisitionResource` using FilamentPHP v5. This interface includes a guided creation wizard, live source stock checking, a line-item repeater with strict positive quantity validations, and header workflow actions executing two-way negotiations and inventory lock triggers.

---

#### Requirements & Specs

##### 1. Creation Wizard Structure (`app/Filament/Resources/TransferRequisitionResource.php`)

Ensure the form schema is built using a progressive `Wizard` component:

*   **Step 1: Location Setup**:
    *   `from_warehouse_id`: Select component loading active origin `Warehouse` options.
    *   `to_warehouse_id`: Select component loading active destination `Warehouse` options.
    *   *Validation*: Enforce that `from_warehouse_id` cannot equal `to_warehouse_id`.

*   **Step 2: Line Item Allocation**:
    Implement a `Repeater` mapping line items to the `TransferRequisitionItem` model.
    ```php
    Forms\Components\Repeater::make('items')
        ->relationship('items')
        ->schema([
            Forms\Components\Select::make('variant_id')
                ->label('Select Product Variant')
                ->options(\App\Models\ProductVariant::pluck('sku', 'id'))
                ->required()
                ->reactive()
                ->afterStateUpdated(function ($state, Forms\Set $set, Forms\Get $get) {
                    // Pull and display live stock balances from the origin warehouse
                    $fromWarehouseId = $get('../../from_warehouse_id');
                    if ($state && $fromWarehouseId) {
                        $stock = \App\Models\WarehouseStock::where('variant_id', $state)
                            ->where('warehouse_id', $fromWarehouseId)
                            ->first();
                        
                        $available = $stock ? ($stock->on_hand_quantity - $stock->reserved_quantity) : 0;
                        $set('live_available_qty', $available);
                    }
                }),

            Forms\Components\Placeholder::make('live_available_qty_placeholder')
                ->label('Live Available Stock at Origin')
                ->content(fn (Forms\Get $get) => number_format($get('live_available_qty') ?? 0) . ' Base Units'),

            Forms\Components\Select::make('requested_unit_name')
                ->label('Unit of Measure')
                ->options(function (Forms\Get $get) {
                    $variantId = $get('variant_id');
                    if (! $variantId) return ['Base Unit' => 'Base Unit'];

                    $variant = \App\Models\ProductVariant::with('unitConversions')->find($variantId);
                    if (! $variant) return ['Base Unit' => 'Base Unit'];

                    $conversions = $variant->unitConversions->pluck('unit_name', 'unit_name')->toArray();
                    return array_merge([$variant->base_unit_name => $variant->base_unit_name], $conversions);
                })
                ->required()
                ->reactive()
                ->afterStateUpdated(function ($state, Forms\Set $set, Forms\Get $get) {
                    // Update the active ratio relative to the base unit
                    $variantId = $get('variant_id');
                    $ratio = 1;
                    if ($variantId) {
                        $conversion = \App\Models\ProductUnitConversion::where('variant_id', $variantId)
                            ->where('unit_name', $state)
                            ->first();
                        $ratio = $conversion ? $conversion->base_unit_ratio : 1;
                    }
                    $set('requested_unit_ratio', $ratio);
                }),

            Forms\Components\Hidden::make('requested_unit_ratio')->default(1),

            Forms\Components\TextInput::make('requested_qty')
                ->label('Requested Qty')
                ->numeric()
                ->required()
                ->minValue(1) // Guardrail 5: Absolute prevention of zero or negative quantities
                ->reactive()
                ->afterStateUpdated(function ($state, Forms\Set $set, Forms\Get $get) {
                    $ratio = $get('requested_unit_ratio') ?? 1;
                    $set('requested_base_qty', (int)$state * (int)$ratio);
                }),

            Forms\Components\Hidden::make('requested_base_qty'),
        ])
        ->required()
        ->minItems(1)
    ```

##### 2. Negotiation Header Actions (`app/Filament/Resources/TransferRequisitionResource/Pages/ViewTransferRequisition.php`)

Header view-actions enable direct control of state transactions and database locks:

*   **Submit Action** (`status` draft → requested):
    Updates state, making the order visible to fulfilling warehouse managers.

*   **Counter-Offer Action** (`status` → `under_review_fulfiller` / `under_review_requestor`):
    Allows modifying quantity thresholds, UoM parameters, or inserting a negotiated physical substitute.
    ```php
    Actions\Action::make('counterOffer')
        ->label('Counter-Offer')
        ->icon('heroicon-o-chat-bubble-left-right')
        ->color('warning')
        ->visible(fn ($record) => in_array($record->status, ['requested', 'under_review_fulfiller', 'under_review_requestor']))
        ->form([
            Forms\Components\Repeater::make('items')
                ->relationship('items')
                ->schema([
                    Forms\Components\Placeholder::make('original_request')
                        ->label('Original Request')
                        ->content(fn ($record, Forms\Get $get) => "Requested: " . $get('requested_qty') . " " . $get('requested_unit_name')),
                    
                    Forms\Components\TextInput::make('approved_qty')
                        ->label('Negotiated/Approved Qty')
                        ->numeric()
                        ->minValue(1) // Enforces non-zero values during negotiations
                        ->required(),

                    Forms\Components\Select::make('approved_unit_name')
                        ->label('Negotiated Unit UoM')
                        ->options(function (Forms\Get $get) {
                            $variantId = $get('variant_id');
                            $variant = \App\Models\ProductVariant::with('unitConversions')->find($variantId);
                            if (! $variant) return [];
                            return array_merge([$variant->base_unit_name => $variant->base_unit_name], $variant->unitConversions->pluck('unit_name', 'unit_name')->toArray());
                        })
                        ->required(),

                    // Guardrail 1: Substitute Variant Selector Integration
                    Forms\Components\Select::make('substitute_variant_id')
                        ->label('Fulfill Using Substitute SKU')
                        ->placeholder('No substitute (fulfill original)')
                        ->options(function (Forms\Get $get) {
                            $originalVariantId = $get('variant_id');
                            // Expose product variants inside the same product parent family
                            $original = \App\Models\ProductVariant::find($originalVariantId);
                            if (! $original) return [];
                            return \App\Models\ProductVariant::where('product_id', $original->product_id)
                                ->where('id', '!=', $originalVariantId)
                                ->pluck('sku', 'id');
                        })
                        ->nullable()
                        ->searchable(),
                ])
        ])
        ->action(function (\App\Models\TransferRequisition $record, array $data) {
            // Recalculate base ratios dynamically for all modified lines
            foreach ($record->items as $index => $item) {
                $formData = $data['items'][$index] ?? null;
                if ($formData) {
                    $ratio = 1;
                    $variantId = $formData['substitute_variant_id'] ?? $item->variant_id;
                    
                    $conversion = \App\Models\ProductUnitConversion::where('variant_id', $variantId)
                        ->where('unit_name', $formData['approved_unit_name'])
                        ->first();
                    $ratio = $conversion ? $conversion->base_unit_ratio : 1;

                    $item->update([
                        'approved_qty' => $formData['approved_qty'],
                        'approved_unit_name' => $formData['approved_unit_name'],
                        'approved_unit_ratio' => $ratio,
                        'approved_base_qty' => (int)$formData['approved_qty'] * (int)$ratio,
                        'substitute_variant_id' => $formData['substitute_variant_id'] ?? null,
                    ]);
                }
            }

            // Route state machine based on the current user's role
            $nextStatus = auth()->user()->hasRole('admin') ? 'confirmed' : (
                $record->status === 'under_review_fulfiller' ? 'under_review_requestor' : 'under_review_fulfiller'
            );
            $record->update(['status' => $nextStatus]);
        });
    ```

*   **Confirm Requisition Action** (`status` → `confirmed`):
    Visible only to managers. Triggers stock reservations:
    ```php
    Actions\Action::make('confirmRequisition')
        ->label('Accept & Confirm Quantities')
        ->color('success')
        ->icon('heroicon-o-check-circle')
        ->visible(fn ($record) => in_array($record->status, ['requested', 'under_review_fulfiller', 'under_review_requestor']))
        ->action(function (\App\Models\TransferRequisition $record, \App\Services\InventoryService $service) {
            // Safely locks physical stock and sets status to 'confirmed'
            $service->lockStockForRequisition($record->id);
        });
    ```

*   **Dispatch Action** (`status` confirmed → dispatched):
    Deducts stock from the origin and launches physical shipments into the transit bucket:
    ```php
    Actions\Action::make('dispatchShipment')
        ->label('Dispatch Shipment')
        ->color('success')
        ->icon('heroicon-o-paper-airplane')
        ->visible(fn ($record) => $record->status === 'confirmed')
        ->action(function (\App\Models\TransferRequisition $record, \App\Services\InventoryService $service) {
            $service->dispatchTransfer($record->id);
        });
    ```
