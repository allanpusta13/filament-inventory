### Phase 14: Automated CI/CD Pipeline & Isolated Testing Environments

#### Objective
Configure a robust Continuous Integration / Continuous Delivery (CI/CD) pipeline using GitHub Actions (`.github/workflows/ci.yml`). Ensure strict validation of code style metrics, execute schema migrations, and run isolated testing environments—routing standard unit tests through an in-memory database to prevent state contamination with Dusk/Playwright E2E browser flows. Deploy a zero-downtime shell release script (`deploy.sh`) for seamless server deployments.

---

#### Requirements & Specs

##### 1. Isolated GitHub Actions Workflow Configuration (`.github/workflows/ci.yml`)

Configure the pipeline workflow to trigger on code updates. This definition isolates unit and feature tests from database-polluting browser tests:

```yaml
name: CI/CD Pipeline

on:
  push:
    branches: [ main, develop ]
  pull_request:
    branches: [ main, develop ]

jobs:
  test-and-build:
    runs-on: ubuntu-latest

    services:
      postgres:
        image: postgres:16-alpine
        env:
          POSTGRES_DB: testing_dusk
          POSTGRES_USER: postgres
          POSTGRES_PASSWORD: password
        ports:
          - 5432:5432
        options: >-
          --health-cmd pg_isready
          --health-interval 10s
          --health-timeout 5s
          --health-retries 5

    steps:
      - name: Checkout Source Code
        uses: actions/checkout@v4

      - name: Setup PHP Environment
        uses: shivammathur/setup-php@v2
        with:
          php-version: '8.3'
          extensions: mbstring, pdo, pdo_pgsql, bcmath, gd, zip, intl, pdo_sqlite
          tools: composer:v2

      - name: Cache Composer Dependencies
        uses: actions/cache@v4
        with:
          path: vendor
          key: ${{ runner.os }}-composer-${{ hashFiles('**/composer.lock') }}
          restore-keys: |
            ${{ runner.os }}-composer-

      - name: Install Composer Dependencies
        run: composer install --prefer-dist --no-interaction --no-progress

      - name: Environment Configuration Setup
        run: |
          cp .env.example .env.testing
          php artisan key:generate --env=testing

      - name: Check Code Formatting Style (Laravel Pint)
        run: ./vendor/bin/pint --test

      # -----------------------------------------------------------------
      # Guardrail 10: Run Unit & Feature Test Suite against isolated In-Memory SQLite
      # -----------------------------------------------------------------
      - name: Run Unit & Feature Test Suite (SQLite Isolated)
        env:
          DB_CONNECTION: sqlite
          DB_DATABASE: ":memory:"
        run: ./vendor/bin/pest --exclude-group=browser

      # -----------------------------------------------------------------
      # Browser Testing Isolation: Configure PostgreSQL for Dusk E2E Tests only
      # -----------------------------------------------------------------
      - name: Prepare PostgreSQL for Headless Dusk Runs
        env:
          DB_CONNECTION: pgsql
          DB_HOST: 127.0.0.1
          DB_PORT: 5432
          DB_DATABASE: testing_dusk
          DB_USERNAME: postgres
          DB_PASSWORD: password
        run: php artisan migrate:fresh --seed --env=testing

      - name: Configure Chrome Driver for Headless E2E Tests
        run: |
          ./vendor/bin/dusk-updater detect --install
          ./vendor/bin/dusk-updater start &

      - name: Start Built-in Application Server
        env:
          APP_ENV: testing
          APP_URL: http://127.0.0.1:8000
          DB_CONNECTION: pgsql
          DB_HOST: 127.0.0.1
          DB_PORT: 5432
          DB_DATABASE: testing_dusk
          DB_USERNAME: postgres
          DB_PASSWORD: password
        run: |
          php artisan serve --port=8000 --env=testing &
          sleep 3

      - name: Run Headless Browser E2E Tests
        env:
          APP_URL: http://127.0.0.1:8000
          DB_CONNECTION: pgsql
          DB_HOST: 127.0.0.1
          DB_PORT: 5432
          DB_DATABASE: testing_dusk
          DB_USERNAME: postgres
          DB_PASSWORD: password
        run: ./vendor/bin/pest --group=browser

      - name: Upload Browser Failure Screenshots on Failure
        if: failure()
        uses: actions/upload-artifact@v4
        with:
          name: dusk-failure-screenshots
          path: |
            tests/Browser/screenshots
            tests/Browser/console
```

##### 2. Production Deployment Shell Script (`deploy.sh`)

A safe, single-run bash script mapping automated dependency compiling, assets caching, database migrations, and maintenance mode refreshes:

```bash
#!/bin/bash
set -e

echo "Starting Production Deployment..."

# 1. Enable Maintenance Mode with Refresh Parameters
php artisan down --refresh=15 --retry=60 || true

# 2. Pull Latest Production Commits
git pull origin main

# 3. Compile Autoloaders and Clear Development Packages
composer install --no-dev --optimize-autoloader --no-interaction

# 4. Clear and Cache Application Configurations
php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan event:cache
php artisan filament:optimize

# 5. Run Database Migrations Programmatically
php artisan migrate --force

# 6. Disable Maintenance Mode
php artisan up

echo "Deployment completed successfully! Live system is operational."
```
