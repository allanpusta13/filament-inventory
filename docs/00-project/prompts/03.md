## 📂 Phase 03: Eloquent Projections & Pure Query-Time Accessors

### Developer Instruction Prompt
Build the Eloquent models with strict relationships. Program the dynamic, query-time inventory aggregate logic directly inside the **`ProductVariant`** model to guarantee that physical stock levels and transit reservations never drift:

1. **`onHandQuantity(int $warehouseId): int`**:
   ```php
   return $this->movements()
       ->where('warehouse_id', $warehouseId)
       ->sum('quantity');
   ```
2. **`reservedQuantity(int $warehouseId): int`**:
   ```php
   return $this->requisitionItems()
       ->whereHas('requisition', function ($q) use ($warehouseId) {
           $q->where('from_warehouse_id', $warehouseId)
             ->whereIn('status', ['confirmed', 'dispatched']);
       })
       ->sum('approved_base_qty');
   ```
3. **`availableQuantity(int $warehouseId): int`**:
   ```php
   return $this->onHandQuantity($warehouseId) - $this->reservedQuantity($warehouseId);
   ```

*Note: Since reservations are computed dynamically, deleting or soft-deleting a confirmed requisition automatically and instantly releases its origin stock reservations because the deleted requisition is naturally excluded from the sum query. No manual column decrements are required.*
