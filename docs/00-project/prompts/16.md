# Phase 16: Automated CI/CD Testing Pipeline & E2E Validation Suite (v3.0)

## Objective
Configure GitHub Actions (`.github/workflows/ci.yml`), Pest PHP unit/feature tests, and Playwright TypeScript E2E browser tests to verify pure derived stock calculations, substitute variant swapping, signed QR URL access control, and multi-language rendering.

---

## Execution Command Matrix

| Test Runner | Environment | Command | Focus Area |
| :--- | :--- | :--- | :--- |
| **Laravel Pint** | Local / CI | `./vendor/bin/pint --test` | Code style compliance |
| **Pest PHP** | SQLite (`:memory:`) | `./vendor/bin/pest` | Unit, Feature, Service & Model tests |
| **Playwright** | PostgreSQL (Dusk DB) | `npx playwright test` | Multi-role E2E browser flows |
