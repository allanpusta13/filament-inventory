1. Add search + sortable columns across ProductResource and
   StockMovementResource tables.
2. Add a date range filter on StockMovementResource (created_at between).
3. Add a "created_by" column on stock_movements (nullable FK to users),
   auto-filled with auth()->id() whenever InventoryService::recordMovement
   is called, and display it in the movements table.

   Receive/Ship/Transfer forms (Adjustment can allow negative), warehouse
   selects required, product select required.

   (e.g. "Catalog" for Products, "Operations" for Stock Movements, "Admin"
