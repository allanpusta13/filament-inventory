### Phase 13: Clean, Role-Scoped Dashboard & Widgets

#### Objective
Configure a custom, role-scoped administration dashboard in FilamentPHP v5. Remove all default information panels, build interactive KPI overview statistics with high-performance short-term caching, and display real-time movement trends and prioritized pending requisitions scoped strictly by location authorizations.

##### 2. Scoped Filtering Dashboard (`app/Filament/Pages/Dashboard.php`)
Ensures that global warehouse dropdown selections are only interactive for Administrators or Auditors:

```php
namespace App\Filament\Pages;

use App\Models\Warehouse;
use Filament\Forms\Components\Select;
use Filament\Forms\Form;
use Filament\Pages\Dashboard as BaseDashboard;
use Filament\Pages\Dashboard\Concerns\HasFiltersForm;

class Dashboard extends BaseDashboard
{
    use HasFiltersForm;

    public function filtersForm(Form $form): Form
    {
        $user = auth()->user();

        // Branch Managers/Staff cannot toggle global filter; metrics are hard-scoped below
        if (! $user->isAdmin() && ! $user->isAuditor()) {
            return $form->schema([]);
        }

        return $form->schema([
            Select::make('warehouse_id')
                ->label('Filter by Warehouse')
                ->options(Warehouse::pluck('name', 'id'))
                ->placeholder('All Warehouses')
                ->searchable()
                ->live(),
        ]);
    }
}
```

##### 3. Guardrail 8: High-Performance Cached Stats Widget (`app/Filament/Widgets/InventoryStatsWidget.php`)

To prevent database locks or memory exhaustion caused by run-time aggregate sum queries across tables containing millions of records, wrap the metrics calculations inside cache drivers with a 5-minute (300-second) invalidation TTL:

```php
namespace App\Filament\Widgets;

use App\Models\InTransit;
use App\Models\LossLedger;
use App\Models\TransferRequisition;
use App\Models\WarehouseStock;
use Filament\Widgets\Concerns\InteractsWithPageFilters;
use Filament\Widgets\StatsOverviewWidget as BaseWidget;
use Filament\Widgets\StatsOverviewWidget\Stat;
use Illuminate\Support\Facades\Cache;

class InventoryStatsWidget extends BaseWidget
{
    use InteractsWithPageFilters;

    protected static ?int $sort = 1;

    protected function getStats(): array
    {
        $user = auth()->user();
        $selectedWarehouse = $this->filters['warehouse_id'] ?? null;

        // Determine accessible warehouse scopes
        $warehouseIds = match (true) {
            ! empty($selectedWarehouse) => [$selectedWarehouse],
            $user->isAdmin() || $user->isAuditor() => null,
            default => $user->warehouses()->pluck('warehouses.id')->toArray(),
        };

        // Cache parameters keyed uniquely by scoped warehouse IDs
        $cacheKey = 'stats_overview_' . ($warehouseIds ? implode('_', $warehouseIds) : 'all');

        $stats = Cache::remember($cacheKey, 300, function () use ($warehouseIds) {
            
            $stockQuery = WarehouseStock::query();
            $inTransitQuery = InTransit::query();
            $requisitionQuery = TransferRequisition::whereIn('status', ['requested', 'under_review_fulfiller', 'under_review_requestor']);
            $lossQuery = LossLedger::query();

            if ($warehouseIds !== null) {
                $stockQuery->whereIn('warehouse_id', $warehouseIds);
                $lossQuery->whereIn('warehouse_id', $warehouseIds);
                $requisitionQuery->where(fn ($q) => 
                    $q->whereIn('from_warehouse_id', $warehouseIds)
                      ->orWhereIn('to_warehouse_id', $warehouseIds)
                );
            }

            return [
                'total_stock' => $stockQuery->sum('on_hand_quantity'),
                'in_transit' => $inTransitQuery->where('status', 'in_transit')->sum('dispatched_base_qty'),
                'pending_requisitions' => $requisitionQuery->count(),
                'loss_value_30_days' => $lossQuery->where('created_at', '>=', now()->subDays(30))->sum('total_financial_loss'),
            ];
        });

        return [
            Stat::make('Total Stock Units', number_format($stats['total_stock']))
                ->description('Units available across warehouses')
                ->color('success')
                ->icon('heroicon-o-cube'),

            Stat::make('Items In-Transit', number_format($stats['in_transit']))
                ->description('Dispatched & awaiting receipt')
                ->color('warning')
                ->icon('heroicon-o-truck'),

            Stat::make('Pending Requisitions', $stats['pending_requisitions'])
                ->description('Action required')
                ->color('info')
                ->icon('heroicon-o-document-magnifying-glass'),

            Stat::make('Total Loss (30 Days)', '$' . number_format($stats['loss_value_30_days'], 4)) // Renders matching decimals precision
                ->description('Damaged / missing items write-off')
                ->color('danger')
                ->icon('heroicon-o-exclamation-triangle'),
        ];
    }
}
```

##### 4. Location-Scoped Urgent Actions Table (`app/Filament/Widgets/PendingRequisitionsWidget.php`)
Displays outstanding actions requiring review, scoped automatically to the manager's branch assignments:

```php
namespace App\Filament\Widgets;

use App\Models\TransferRequisition;
use Filament\Tables;
use Filament\Tables\Table;
use Filament\Widgets\TableWidget as BaseWidget;

class PendingRequisitionsWidget extends BaseWidget
{
    protected static ?int $sort = 3;
    protected int | string | array $columnSpan = 'full';

    public function table(Table $table): Table
    {
        $user = auth()->user();

        return $table
            ->query(
                TransferRequisition::query()
                    ->whereIn('status', ['requested', 'under_review_fulfiller', 'under_review_requestor'])
                    ->when(! $user->isAdmin() && ! $user->isAuditor(), function ($query) use ($user) {
                        $ids = $user->warehouses()->pluck('warehouses.id');
                        $query->whereIn('from_warehouse_id', $ids)->orWhereIn('to_warehouse_id', $ids);
                    })
                    ->latest()
                    ->limit(5)
            )
            ->columns([
                Tables\Columns\TextColumn::make('reference_code')->bold()->searchable(),
                Tables\Columns\TextColumn::make('fromWarehouse.name')->label('Origin'),
                Tables\Columns\TextColumn::make('toWarehouse.name')->label('Destination'),
                Tables\Columns\TextColumn::make('status')
                    ->badge()
                    ->color(fn (string $state): string => match ($state) {
                        'requested' => 'warning',
                        'under_review_fulfiller', 'under_review_requestor' => 'info',
                        default => 'gray',
                    }),
                Tables\Columns\TextColumn::make('created_at')->dateTime()->label('Submitted'),
            ])
            ->actions([
                Tables\Actions\Action::make('view')
                    ->url(fn (TransferRequisition $record): string => route('filament.admin.resources.transfer-requisitions.edit', $record)),
            ]);
    }
}
```
