## 📂 Phase 13: Glassmorphic Bento Dashboard & Performance Caching

### Developer Instruction Prompt
Build a custom **Dashboard Page** utilizing a dense, responsive **Bento Grid** layout. Display statistics blocks with performance optimizations to handle millions of transaction records efficiently:

1. **Stats Overview Widget**:
   * Displays KPI stats: *Total Active In-Transit Volume*, *Total Discrepancies (30 Days)*, *Pending Action Queue*, and *Total Stock Units*.
   * **Bashing the Database sum() Overhead**: Wrap heavy widget sum calculations in a cache tag (`Cache::remember()`) with a **300-second expiration scope**. Configure model event listeners on `stock_movements` and `transfer_requisitions` to bust and clear the cache instantly when a transaction is committed.
2. **Dashboard Scoping**:
   * Hard-scope metrics displayed to Branch Managers and Staff to include only locations assigned to them in the pivot, leaving dropdown filters interactive solely for Admins and Auditors.
