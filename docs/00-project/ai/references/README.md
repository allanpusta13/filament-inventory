# AI References

Store supporting project-specific reference material here.

Examples:

- domain rules
- naming conventions
- UI conventions
- testing conventions
- integration notes
- stable implementation constraints

References are advisory context. They do not override:

1. current user requirements
2. PRD / approved specification
3. `CLAUDE.md`
4. Vibe Coding Standard
5. Vibe Coding Guideline

Keep references focused and current. If a reference becomes obsolete, update or remove it rather than allowing the AI to infer which version is authoritative.


## Standard AI tools

### Context7
Use Context7 for version-sensitive external library/framework documentation and code examples before implementation. Record material version/source decisions in the relevant plan or research document.

### EnvKit
When EnvKit is the local stack, its MCP integration may be used for environment inspection and controlled local operations under the project's autonomy rules.
